# HeatMapCAD - Тепловая карта активности в КОМПАС-3D

Приложение для создания тепловых карт активности пользователя при работе в САПР КОМПАС-3D. Программа отслеживает движения мыши и создает визуализацию в виде тепловой карты, показывающей области наибольшей активности.

## Возможности

- Отслеживание движений мыши в реальном времени
- Создание тепловых карт с настраиваемыми параметрами
- Сохранение и загрузка данных отслеживания
- Экспорт тепловых карт в различные форматы
- Настройка параметров визуализации:
  - Разрешение
  - Яркость
  - Размер областей
  - Чувствительность
  - Цветовая схема

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/heatmap-cad.git
cd heatmap-cad
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/Mac
.venv\Scripts\activate     # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

1. Запустите приложение:
```bash
python run.py
```

2. Нажмите "Начать отслеживание" для начала записи движений мыши
3. Работайте в КОМПАС-3D как обычно
4. Нажмите "Завершить отслеживание" для остановки записи
5. Настройте параметры визуализации по желанию
6. Сохраните тепловую карту в файл

## Подробное описание компонентов

### Ядро приложения (core/)
- `input_tracker.py` - Абстрактный базовый класс для всех трекеров устройств ввода. Определяет основной интерфейс для отслеживания.
- `mouse_tracker.py` - Реализация трекера мыши. Использует библиотеку pynput для отслеживания движений мыши и создания скриншотов.

### Управление данными (data/)
- `data_manager.py` - Менеджер данных для сохранения и загрузки треков. Обрабатывает файлы JSON с информацией о движениях мыши.

### Визуализация (visualization/)
- `base_visualizer.py` - Базовый класс для всех визуализаторов. Определяет общий интерфейс.
- `heatmap_visualizer.py` - Создает тепловые карты используя matplotlib. Поддерживает различные настройки визуализации.

### Сетевое взаимодействие (network/)
- `client.py` - Сетевой клиент для синхронизации данных и проверки обновлений. Использует requests для HTTP-запросов.

### Пользовательский интерфейс (ui/)
- `main_window.py` - Главное окно приложения. Создано с использованием ttkbootstrap для современного внешнего вида.

### Утилиты (utils/)
- `config.py` - Управление конфигурацией приложения. Работает с JSON-файлами настроек.
- `sound.py` - Воспроизведение системных звуков для уведомлений.

### Конфигурация
- `config.json` - Основной файл конфигурации с настройками по умолчанию для всех компонентов.

### Запуск
- `run.py` - Точка входа в приложение. Настраивает PYTHONPATH и обрабатывает ошибки запуска.

## Требования

- Python 3.8 или выше
- Основные зависимости:
  - matplotlib >= 3.7.0 (визуализация)
  - numpy >= 1.24.0 (обработка данных)
  - pynput >= 1.7.6 (отслеживание мыши)
  - ttkbootstrap >= 1.10.1 (пользовательский интерфейс)
  - PyAutoGUI >= 0.9.54 (создание скриншотов)
  - scipy >= 1.10.0 (обработка данных для тепловой карты)
