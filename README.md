# HeatMapCAD - Тепловая карта активности в САПР системах

Приложение для создания тепловых карт активности пользователя при работе в САПР системах (КОМПАС-3D, AutoCAD и др.). Программа отслеживает движения мыши и создает визуализацию в виде тепловой карты, показывающей области наибольшей активности.

## Возможности

- Отслеживание движений мыши в реальном времени
- Создание тепловых карт с настраиваемыми параметрами
- Сохранение и загрузка данных отслеживания
- Экспорт тепловых карт в различные форматы
- Отправка данных на сервер для анализа
- Настройка параметров визуализации:
  - Разрешение
  - Яркость
  - Размер областей
  - Чувствительность
  - Цветовая схема

## Требования

- Python 3.8 или выше
- Доступ в интернет для первоначальной установки зависимостей

## Установка и запуск

### Для обычных пользователей (рекомендуется)

1. Скачайте архив `HeatMapCAD_Portable.zip` с [официального сайта](https://heatmapcad.ru/download) или из раздела [Releases](https://github.com/fylhtq7779/HeatMapCAD_DV/releases)
2. Распакуйте архив в любую директорию
3. Запустите:
   - В Windows: дважды щелкните на файле `start_heatmap.bat`
   - В Linux/macOS: запустите `start_heatmap.sh` (возможно, потребуется сделать файл исполняемым: `chmod +x start_heatmap.sh`)
4. При первом запуске будут автоматически установлены все необходимые зависимости

### Для разработчиков

1. Клонируйте репозиторий:
```bash
git clone https://github.com/fylhtq7779/HeatMapCAD_DV.git
cd HeatMapCAD_DV
```

2. Запустите приложение:
```bash
# Windows
start_heatmap.bat

# Linux/macOS
chmod +x start_heatmap.sh
./start_heatmap.sh
```

## Использование

1. При первом запуске введите свои данные (ФИО, группа, программа)
2. Нажмите "Начать отслеживание" для начала записи движений мыши
3. Работайте в САПР системе как обычно
4. Нажмите "Завершить отслеживание" для остановки записи
5. Настройте параметры визуализации по желанию
6. Сохраните тепловую карту в файл или отправьте на сервер

## Создание портативной версии

Для создания портативного архива с приложением:

```bash
python create_portable_archive.py
```

После выполнения этой команды в корневой директории появится файл `HeatMapCAD_Portable_YYYYMMDD.zip`, который можно распространять.

## Возможные проблемы и их решение

### Python не найден

Если вы получаете сообщение "Python не найден", убедитесь, что:
1. Python установлен на вашем компьютере
2. Python добавлен в переменную PATH
3. Вы можете проверить установку Python, открыв командную строку/терминал и введя:
   ```
   python --version
   ```
   или
   ```
   python3 --version
   ```

### Ошибка при установке зависимостей

Если возникают проблемы при установке зависимостей:
1. Убедитесь, что у вас есть доступ в интернет
2. Проверьте, что у вас есть права на установку пакетов
3. Попробуйте установить зависимости вручную:
   ```
   pip install -r requirements.txt
   ```
   или
   ```
   pip3 install -r requirements.txt
   ```

### Приложение не запускается

Если приложение не запускается после установки зависимостей:
1. Проверьте файл `launch_log.txt` для получения информации об ошибке
2. Проверьте файл `error_log.txt`, если он был создан
3. Убедитесь, что все файлы проекта на месте, особенно директория `src` и файл `src/main.py`

## API интеграция

Приложение поддерживает отправку данных на API сервер для анализа. Данные отправляются в формате multipart/form-data с полем `file`, содержащим JSON файл с данными о движениях мыши.

Пример отправки данных через curl:
```bash
curl -X POST "https://packsandmods.ru/heatmap/api/heatmap/upload" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@data.json"
```

## Требования к зависимостям

Основные зависимости:
- matplotlib >= 3.7.0 (визуализация)
- numpy >= 1.24.0 (обработка данных)
- pynput >= 1.7.6 (отслеживание мыши)
- ttkbootstrap >= 1.10.1 (пользовательский интерфейс)
- PyAutoGUI >= 0.9.54 (создание скриншотов)
- scipy >= 1.10.0 (обработка данных для тепловой карты)
- requests >= 2.28.0 (HTTP запросы)
