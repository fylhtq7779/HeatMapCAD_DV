# Описание релиза HeatMapCAD Portable

## Версия 1.0.0 (26.02.2025)

### Основные возможности

- **Отслеживание движения мыши**: Программа записывает все движения мыши во время работы в CAD-программах.
- **Визуализация тепловой карты**: Создание наглядных тепловых карт на основе данных о движении мыши.
- **Настройка параметров визуализации**: Возможность тонкой настройки параметров отображения тепловой карты (разрешение, яркость, размер, чувствительность, цветовая схема).
- **Локальное сохранение данных**: Все записи движения мыши сохраняются локально для последующего анализа.
- **Экспорт тепловых карт**: Возможность сохранения тепловых карт в формате PNG.
- **Автоматическая настройка**: Программа автоматически создает виртуальное окружение и устанавливает все необходимые зависимости при первом запуске.
- **Скрытый запуск**: После первой установки программа запускается без отображения консоли для удобства использования.

### Новые функции

- **Отключение отправки данных**: Добавлена возможность отключить отправку данных тепловой карты на сервер через настройки программы.
- **Валидация данных пользователя**: Улучшена проверка вводимых пользователем данных в диалоге первого запуска.
- **Улучшенный интерфейс**: Обновлен пользовательский интерфейс с улучшенной навигацией и информативностью.

### Исправления

- Исправлены ошибки в логике скрытого запуска программы.
- Улучшена видимость вывода консоли при первой установке.
- Исправлены проблемы с отображением скриншотов в некоторых случаях.
- Улучшена стабильность работы при длительном отслеживании.

### Установка и запуск

1. Распакуйте архив `HeatMapCAD_Portable_20250226.zip` в удобное место на компьютере.
2. Запустите файл `start_heatmap.bat` для начала работы.
3. При первом запуске программа автоматически настроит все необходимые компоненты и запросит ваши данные.
4. После успешной установки будет создан файл `HeatMapCAD.vbs` для последующих запусков программы без отображения консоли.

### Системные требования

- Windows 10/11 (64-bit)
- Python 3.8 или выше (устанавливается автоматически)
- 500 МБ свободного места на диске
- 4 ГБ оперативной памяти
