# Руководство пользователя HeatMapCAD

## Введение

HeatMapCAD - это приложение для создания тепловых карт активности пользователя при работе в САПР системах (КОМПАС-3D, AutoCAD и др.). Программа отслеживает движения мыши и создает визуализацию в виде тепловой карты, показывающей области наибольшей активности.

## Установка

1. Запустите файл установщика `HeatMapCAD_Setup.exe`
2. Следуйте инструкциям мастера установки
3. После завершения установки на рабочем столе появится ярлык программы

## Запуск программы

Для запуска программы просто дважды щелкните по ярлыку `HeatMapCAD` на рабочем столе или в меню "Пуск".

## Использование программы

### Первый запуск

При первом запуске программы вам будет предложено ввести следующую информацию:
- ФИО
- Номер группы
- Название программы, в которой вы работаете (например, "КОМПАС-3D", "AutoCAD" и т.д.)

Эта информация будет сохранена и использована при создании отчетов и тепловых карт.

### Основные функции

1. **Начать отслеживание** - нажмите эту кнопку, чтобы начать запись движений мыши
2. **Завершить отслеживание** - нажмите эту кнопку, чтобы остановить запись
3. **Создать тепловую карту** - создает визуализацию активности в виде тепловой карты
4. **Сохранить тепловую карту** - сохраняет тепловую карту в файл
5. **Отправить данные** - отправляет данные на сервер для анализа

### Настройки визуализации

Вы можете настроить параметры визуализации тепловой карты:
- **Разрешение** - качество изображения тепловой карты
- **Яркость** - интенсивность цветов на тепловой карте
- **Размер областей** - размер "горячих" точек на карте
- **Чувствительность** - порог активности для отображения на карте
- **Цветовая схема** - выбор цветовой палитры для тепловой карты

## Часто задаваемые вопросы

### Программа не запускается

Убедитесь, что:
- Установка была завершена успешно
- У вас есть права администратора для запуска программы
- Антивирус не блокирует запуск программы

### Как удалить программу?

Для удаления программы используйте стандартный инструмент "Установка и удаление программ" в Панели управления Windows.

### Где хранятся данные?

Данные о движениях мыши и созданные тепловые карты хранятся в папке установки программы, в подпапках `data` и `mouse_tracks`.
